Claude Code 安装与 DeepSeek 配置指南：4 个环境变量快速配通

发表于2026-08-19|更新于2026-08-19|AI 工具实践
|浏览量:

如果你想继续用 Claude Code 的交互方式和工具链，但又不想走 Anthropic 官方付费授权，这篇就够了。核心思路很简单：Claude Code 继续当前端，推理后端改成 DeepSeek 的 Anthropic 兼容接口。

这不是“破解”或“魔改”，本质上是一次标准的 API 兼容接入。你只需要把安装、环境变量和验证这三步配通，就能在终端里直接用起来。

先说结论

想把 Claude Code 接到 DeepSeek，最关键的是 4 个配置：

  1. ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
  2. ANTHROPIC_AUTH_TOKEN=你的 DeepSeek API Key
  3. ANTHROPIC_MODEL=deepseek-v4-pro[1m]
  4. ANTHROPIC_SMALL_FAST_MODEL=deepseek-v4-flash

配好以后，启动 claude，再用 /model 检查当前模型是否已经切到 DeepSeek 即可。

一、安装前要准备什么

正式安装前，先确认几件事：

  • 操作系统满足 Claude Code 官方要求
  • Windows 用户最好先装 Git for Windows
  • 本机已经有可用的 Node.js 环境
  • 安装阶段如果网络受限，要先准备代理
  • 你已经在 DeepSeek 开放平台创建好 API Key

如果这些前置条件没准备好，后面最常见的问题就是：装不上、命令找不到、启动后还提示登录。

另外，Claude Code 现在也支持图形化安装路径，例如 macOS 的 Homebrew 和 Windows 的 WinGet；但如果你只想最快跑通，直接用官方脚本最省事。

三、为什么能接入 DeepSeek

Claude Code 默认走 Anthropic 接口，但 DeepSeek 提供了 Anthropic 兼容端点，所以你不需要改 Claude Code 的使用方式，只需要把请求地址和鉴权信息换掉。

根据 DeepSeek 当前文档，推荐直接使用 deepseek-v4-pro 和 deepseek-v4-flash。其中 V4 系列支持更长上下文，适合 Claude Code 这类会读代码库、跑多轮任务的 Agent 场景。

ANTHROPIC_MODEL deepseek-v4-pro[1m]

  2. ANTHROPIC_BASE_URL 是否写错或多了斜杠
  3. API Key 是否可用
  4. 是否还在用旧模型名

六、日常怎么用更顺手

配通之后，真正高频的其实不是“安装”，而是日常使用习惯。

建议记住这几个命令和操作：

  • 在项目目录里启动 claude
  • 输入 / 查看全部内置命令
  • 用 /clear 清空当前对话
  • 用 /compact 压缩上下文
  • 用 /init 生成项目说明文件
  • 用 claude --continue 续接最近一次对话

另外，Shift + Tab 可以切权限模式：

  • default：每次写文件或执行命令都确认，适合稳妥场景
  • acceptEdits：自动接受编辑，适合快速迭代
  • plan：只给方案不动文件，适合先评估再执行

七、最常见的 4 个问题

1. 安装阶段网络报错

Claude Code 官方安装脚本拉取阶段通常需要能访问外网。这个阶段报错，优先处理代理，不要上来就怀疑 Node 或 npm。

2. 安装完后 claude 命令找不到

这通常是 PATH 没生效。重开终端后再试；如果仍不行，再检查 Node 和全局 bin 目录是否在 PATH 里。

3. 启动后还是提示登录

说明 DeepSeek 路由没有真正生效。大多数情况都是环境变量漏配、写错，或者当前 shell 没重新加载配置。

4. 上下文太长、响应越来越慢

可以先执行 /compact 压缩上下文，再继续当前任务。对于特别大的项目，也可以把轻量任务交给 deepseek-v4-flash。

最后总结

如果你想低成本继续使用 Claude Code，最省事的路径不是换工具，而是把后端切到 DeepSeek。

你真正需要做的只有三件事：

  1. 按官方方式安装 Claude Code
  2. 配好 4 个环境变量
  3. 启动后用 /model 做一次验证

一旦这三步跑通，后面你在终端里的使用方式几乎不用改，写代码、读项目、跑命令的体验也能保持一致。
