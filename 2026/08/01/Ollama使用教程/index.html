一、Ollama 是什么

Ollama 是一款本地大模型运行时，把「下载模型 → 加载推理 → 提供 API」做成一条命令即可完成的体验，常被比作 「大模型界的 Docker」。

能力 说明
本地运行 模型在本机推理，默认不上传提示词与对话内容
一条命令开聊 ollama run <模型名> 自动拉取并进入对话
内置 HTTP API 默认 http://localhost:11434，便于接入应用
官方 SDK 提供 Python、JavaScript 库
可定制 通过 Modelfile 改系统提示、参数、导入 GGUF
生态集成 可对接 Claude Code、Codex、VS Code、各类 Agent

适合场景：本地私有对话、RAG、代码助手、离线推理、把 OpenAI 风格接口指向本机。

官方入口：

  • 官网 / 下载：https://ollama.com
  • 模型库：https://ollama.com/search
  • 文档：https://docs.ollama.com

十、环境变量与服务配置

服务端配置主要通过启动时的环境变量生效，改完后需重启 Ollama。

10.1 高频变量

变量 作用 常见设置
OLLAMA_HOST 监听地址 0.0.0.0:11434（局域网访问）
OLLAMA_MODELS 模型目录 外置 SSD 路径
OLLAMA_ORIGINS CORS 允许来源 浏览器扩展需额外放行
OLLAMA_KEEP_ALIVE 模型闲置保活 5m、-1
OLLAMA_CONTEXT_LENGTH 默认上下文长度 8192、64000
OLLAMA_NUM_PARALLEL 单模型并行请求数 1、4（显存随并行线性涨）
OLLAMA_MAX_LOADED_MODELS 同时加载模型数上限 按显存调整
OLLAMA_MAX_QUEUE 排队上限，过载返回 503 默认 512
OLLAMA_FLASH_ATTENTION Flash Attention 1 开启
OLLAMA_KV_CACHE_TYPE KV 缓存量化 f16 / q8_0 / q4_0
OLLAMA_NO_CLOUD 关闭云功能 1
HTTPS_PROXY 拉取模型走代理 公司代理地址

上下文经验：做 Agent / 长文档 / 联网检索时，常需把上下文提到 至少 64K；但上下文越大越吃显存。可用 ollama ps 看 PROCESSOR 是否仍是 100% GPU。

十三、硬件与选型建议

13.1 GPU 是否生效

  • 100% GPU：理想，推理最快
  • 100% CPU：能跑但慢，注意散热与风扇
  • CPU/GPU 混合：模型或上下文过大，部分层在内存，通常变慢

13.2 上下文与显存

官方大致默认策略（会随版本与机器显存调整）：

显存量级 默认上下文量级
< 24 GiB 约 4K
24～48 GiB 约 32K
≥ 48 GiB 可到很高（如 256K 量级）

Agent / 编码工具建议主动把上下文调到 ≥ 64K，并确认仍是 GPU 满载。

省显存手段：

  • 换更小模型或更高量化
  • 降低 num_ctx / OLLAMA_CONTEXT_LENGTH
  • 开启 Flash Attention，KV 缓存用 q8_0
  • 降低 OLLAMA_NUM_PARALLEL

13.3 选型口诀

  1. 先能跑起来：从 3B～8B 开始，确认延迟可接受。
  2. 按任务换模型：代码用 coder 系列，中文优先 Qwen 系。
  3. 质量不够再加大：同系列升参数，或降低量化压缩。
  4. 本机吃力再用 cloud tag / 远程 GPU。

14.2 拉取模型失败 / 很慢

  • 检查网络与 DNS
  • 公司网络设置 HTTPS_PROXY（不要乱设 HTTP_PROXY，可能干扰本机客户端连接）
  • 换网络或镜像源环境后再 ollama pull

14.3 回答很慢或占满内存

  • ollama ps 看是否掉到 CPU
  • 减小模型或 num_ctx
  • ollama stop <model> 释放显存后再跑更小模型
  • 避免同时加载过多模型（调低 OLLAMA_MAX_LOADED_MODELS）

14.7 隐私边界

  • 本地模型：提示词与回复在本地处理，Ollama 默认看不到你的对话内容。
  • Cloud 模型：请求会发到 Ollama 云端以完成推理；官方说明不将内容用于训练，但仍属于远程处理。敏感数据优先本地模型 + OLLAMA_NO_CLOUD=1。

14.8 开机自启关闭

  • Windows：任务管理器 → 启动应用 → 禁用 Ollama
  • macOS：系统设置 → 登录项 → 关闭 Ollama 后台项
