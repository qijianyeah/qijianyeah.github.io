Claude Code 内置命令完全指南：会话、上下文与日常工作流

发表于2026-08-21|更新于2026-08-21|AI 工具实践
|浏览量:

在 Claude Code 里敲 /，就能调出内置斜杠命令。它们不负责「写代码本身」，而是管会话、上下文、模型、成本、导出和诊断——用好这批命令，长对话不容易爆窗，排查环境也更快。本文按源笔记里的命令表整理，并补上场景说明与截图。

说明：<arg> 表示必需参数，[arg] 表示可选参数。并非所有命令对每个用户都可见，部分命令取决于平台、计划或环境（例如 /desktop 通常只在 macOS / Windows 上出现）。

1. 怎么发现命令

在 Claude Code 输入框中：

  1. 输入 /：列出当前环境可用的全部命令
  2. 输入 / 后再跟若干字母：按前缀筛选，例如 /co 会收窄到 /compact、/config、/copy、/cost 等

先记住「斜杠 + 筛选」，比死记全表更实用。

2. 命令速查表

命令 用途
/add-dir <path> 把指定目录加入当前会话的工作目录列表，让 Claude Code 同时访问多个代码目录
/btw <question> 提出快速附加问题，不写入正式对话历史
/clear 清空当前对话历史，释放占用的上下文空间
/color <color> 为当前会话设置提示栏颜色；可用 red、blue、green、yellow、purple、orange、pink、cyan；default 重置
/compact [instructions] 压缩对话：清空细节，但保留一份文字摘要进入新上下文；可看作 /clear 的「升级版」
/config 打开设置界面，调整主题、模型、输出样式等偏好
/context 用彩色网格可视化上下文占用，并给出优化建议
/copy [N] 把助手最近一次回复复制到剪贴板；/copy 2 复制倒数第二条
/cost 显示本会话累计的 Token 用量与估算成本
/doctor 自动检查安装、配置与运行环境，给出验证结果或修复建议
/exit 退出 CLI
/export [filename] 将当前对话导出为纯文本；带文件名则直接写入文件，否则弹出保存/复制选项
/init 初始化项目，生成结构化 CLAUDE.md，帮助模型理解项目约定
/login / /logout 登录 / 登出 Anthropic 账户
/model [model] 选择或切换 AI 模型；支持的模型可用左右箭头调工作量级别，切换立即生效
/rewind 回滚对话，把会话恢复到历史上某一次状态
/theme 更改颜色主题（浅色/深色、色盲友好、ANSI 等）

下文按场景展开。有截图的命令会附演示图。

3. 会话与上下文

长任务最怕两件事：上下文塞满，以及「清掉对话后把关键结论也弄没了」。这一节的命令专门对付它们。

3.1 /btw：旁路提问，不污染主线

/btw 适合临时查概念、确认术语，又不想把旁支问答写进正式历史。回车后可以看到：这次提问不会出现在过往正式对话记录里。

适用场景：

  • 主任务在改业务代码，突然想确认某个 API 语义
  • 不想让「闲聊式」问答挤占后续上下文预算

3.2 /clear：彻底清空会话

清空当前对话历史，并释放被占用的上下文空间。适合「这条线已经跑偏，从头再来」的时刻。

注意：/clear 不保留摘要。若你还需要前面的结论、已确认的方案、关键接口约定，优先用下一节的 /compact。

3.3 /compact：压缩而不是扔掉

/compact 会清空详细历史，但生成并保留一份文字摘要，再放进新的上下文。可选参数 instructions 用来告诉压缩过程「哪些必须保住」。

和 /clear 的对比：

/clear /compact
历史细节 全部丢掉 丢掉细节
摘要 无 有，可带压缩指令
典型用途 换题、推倒重来 同题续作、上下文将满

实践建议：出现上下文告警时，先 /compact（必要时加指令），再继续干同一件事；只有确定旧会话完全没用时，才 /clear。

3.4 /context：看清楚上下文花在哪

用彩色网格展示当前上下文占用，标出上下文密集型工具、内存膨胀和容量警告，并给出优化建议。

建议在以下时机打开 /context：

  1. 感觉回复变慢、变飘，怀疑窗口快满了
  2. /compact 前后各看一次，验证压缩是否生效
  3. 排查「是不是某个工具/大文件把预算吃光了」

3.5 /rewind：回到历史上的某次状态

回滚对话，把会话恢复到历史中的某一次。适合「刚才那次改动方向错了，想退回到改之前」——比整段 /clear 更精细。

与 /compact 的分工：

  • /rewind：时间旅行，回到过去的一个检查点
  • /compact：保留摘要后继续向前，但细节变薄

4. 多目录与项目初始化

4.1 /add-dir：一次会话管多个目录

把指定目录加入当前会话的工作目录列表后，Claude Code 可以同时访问、理解多个目录下的代码。适合：

  • 业务仓 + 公共组件仓
  • 前端仓 + 后端仓联动改接口
  • 主工程 + 样例工程对照阅读

加入前确认路径正确、权限可读；敏感目录不要随手加进会话。

4.2 /init：生成项目级 CLAUDE.md

为项目创建结构化文档 CLAUDE.md，让后续会话更容易对齐项目约定（构建方式、目录结构、编码规范、测试命令等）。新仓库或团队规范尚未落盘时，优先跑一次 /init，再按需手工精修 CLAUDE.md。

5. 模型、主题与配置

5.1 /model：切换模型与工作量级别

用于选择或更改 AI 模型。对支持的模型，可用左右箭头调整工作量级别。更改立即生效，不必等当前响应跑完。

选型直觉（按你实际可用模型为准）：

  • 探索、重构、复杂推理：偏强模型
  • 大批量机械改写、简单补全：可切更省的模型，配合 /cost 观察开销

5.2 /config：集中改偏好

打开设置界面，可调整主题、模型、输出样式等偏好。适合一次性改多项，而不是分散用多个斜杠命令。

5.3 /theme：换配色主题

更改颜色主题，包含浅色/深色变体、色盲友好（道尔顿化）主题，以及使用终端调色板的 ANSI 主题。

5.4 /color：给当前会话贴色标

为当前会话设置提示栏颜色。可用：red、blue、green、yellow、purple、orange、pink、cyan；default 重置。

多窗口并行时很有用：例如蓝色窗口专门改后端，绿色窗口专门写测试，避免串台。

6. 复制、导出与成本

6.1 /copy：把回复立刻贴出去

将最后一个助手响应复制到剪贴板。传数字 N 可复制第 N 个最新响应：/copy 2 复制倒数第二个。

执行后可直接在外部 Ctrl/Cmd + V 粘贴。适合把方案贴进文档、工单或群聊。

6.2 /export：整段对话落盘

将当前对话导出为纯文本。带文件名时直接写入该文件；不带文件名时，会打开对话框让你复制到剪贴板或另存为文件。

源笔记演示中，会在项目里生成类似 session.txt 的文件保存对话内容，方便归档或事后检索。

6.3 /cost：看本会话花了多少

显示 Token 使用统计，以及从当前会话开始至今累积的估算成本。

建议习惯：

  1. 大任务中途看一眼 /cost，决定要不要换模型或先 /compact
  2. 对比「强模型短会话」和「弱模型长会话」的真实花费

7. 诊断与账户

7.1 /doctor：环境自检

运行一系列自动化检查，诊断 Claude Code 的安装、设置与运行环境，并给出验证结果或修复建议。装完、换机、代理/模型突然不通时，优先跑它。

7.2 /login 与 /logout

登录或登出 Anthropic 账户。切换账号、权限异常、需要刷新登录态时使用。

7.3 /exit

退出 Claude Code CLI。与「清会话」不同：它结束的是进程本身。

8. 日常工作流建议

可以把常用命令串成固定节奏：

并行多会话时：用 /color 给窗口染色，用 /model 按任务轻重分流，用 /btw 消化旁支问题，避免主线历史被冲淡。

9. 小结

Claude Code 内置命令可以粗分成四类：

  1. 管上下文：/clear、/compact、/context、/rewind、/btw
  2. 管项目范围：/add-dir、/init
  3. 管体验与模型：/model、/config、/theme、/color
  4. 管产出与运维：/copy、/export、/cost、/doctor、/login、/logout、/exit

记不清具体名字时，在输入框敲 / 再筛选即可。真正拉开效率差距的，往往不是「会不会写 Prompt」，而是会不会在上下文将满、任务跑偏、多仓协作时，及时用对 /compact、/rewind、/add-dir 和 /context。
