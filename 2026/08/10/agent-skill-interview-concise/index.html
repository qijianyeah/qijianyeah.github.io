面试回答准备：什么是 Skill？如何创建 Skill（精简版）

本文用于技术面试快速回答准备，建议将回答控制在 2～3 分钟。

如果面试官要求继续展开，可阅读：《面试回答准备：什么是 Skill？如何创建 Skill（完整版）》。

一、什么是 Skill？

Skill 是给 AI Agent 使用的可复用能力包，用于封装某类任务的专业知识、触发条件、执行流程和安全边界。

它以 SKILL.md 为核心，还可以包含：

  • scripts/：确定性操作脚本；
  • references/：规范和参考资料；
  • assets/：模板及静态资源。

它不是简单的长提示词，而是让 Agent 明确：

  1. 什么时候使用；
  2. 如何稳定完成任务；
  3. 哪些高风险操作必须经过用户确认。

二、如何创建 Skill？

主要分为五步：

1. 明确适用场景

优先选择可重复、有稳定流程、需要专业知识或固定规范的任务。

2. 创建 SKILL.md

配置 name 和 description。其中 description 要同时说明“能做什么”和“什么时候触发”。

3. 定义流程和完成标准

明确任务输入、执行步骤、校验方式，以及什么状态算完成。

4. 拆分配套资源

核心流程放在 SKILL.md，确定性操作放入 scripts/，长篇资料放入 references/，模板放入 assets/。

5. 设置安全边界并测试

发布、部署、删除、发送消息等外部操作必须先获得用户确认。同时测试 Skill 是否准确触发、能否正确处理异常，以及结果是否符合完成标准。

三、一句话总结

Skill 的核心，是把可复用任务沉淀成“准确触发、稳定执行、边界清晰”的 Agent 能力模块。
