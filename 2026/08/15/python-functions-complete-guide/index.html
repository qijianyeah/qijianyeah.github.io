2. 为什么要使用函数

函数的核心思想是：把相对独立、可能重复使用的逻辑封装起来，并通过参数接收变化的数据。

使用函数主要有以下好处：

  1. 提高复用性：一次定义，可以多次调用。
  2. 降低重复：相同逻辑不需要复制多份。
  3. 方便维护：需求变化时，只修改函数内部即可。
  4. 结构清晰：把复杂程序拆分成多个职责明确的小模块。
  5. 便于测试：可以单独验证每个函数的输入和输出。

可以把函数理解成一台机器：

参数和返回值都不是必需的，一个函数可以：

  • 没有参数，也没有显式返回值；
  • 有参数，但没有显式返回值；
  • 没有参数，但有返回值；
  • 既有参数，也有返回值。

3.1 内置函数

常用内置函数包括 print()、input()、len()、type()、int()、str()、max()、min() 和 sum() 等。

4. 形参与实参

4.1 基本概念

  • 形参（形式参数）：定义函数时，写在括号中的变量，相当于等待接收数据的占位符。
  • 实参（实际参数）：调用函数时，真正传入的值。

形参通常只在函数内部有效。函数每调用一次，形参都会接收本次调用传入的实参。

4.2 Python 参数不固定类型

Python 是动态类型语言。形参本身不会限制实参类型，真正能否运行取决于函数内部操作是否支持该类型。

5. 参数的传递方式

5.1 位置参数

位置参数按照实参出现的位置，与形参从左到右依次对应。

位置参数的顺序和数量必须符合函数定义，否则可能传错数据或抛出 TypeError。

5.2 关键字参数

关键字参数使用 形参名=实参值 的形式传递，因此不受书写顺序影响。

9. 类型注解与文档字符串

9.1 类型注解

Python 3.5 以后可以为参数和返回值添加类型注解：

  • number: int：表示建议给 number 传入整数。
  • -> int：表示函数预期返回整数。

类型注解主要用于：

  • 帮助开发者理解函数接口；
  • 让 IDE 提供更准确的提示；
  • 配合 mypy、Pyright 等静态检查工具发现问题；
  • 提高大型项目的可维护性。

12. 默认参数的常见陷阱

12.1 可变对象作为默认值

默认参数在函数定义时只创建一次，不会在每次调用时重新创建。因此，不应直接使用列表、字典或集合等可变对象作为默认值。

三次调用复用了同一个默认列表，这通常不是开发者期望的结果。

数字、字符串、元组等不可变对象作为默认值时，通常不会产生状态共享问题。

13. 本章总结

13.1 核心知识

  1. 使用 def 定义函数，使用 函数名() 调用函数。
  2. 参数是函数的输入，return 是函数的输出。
  3. 形参写在定义处，实参写在调用处。
  4. 实参可以按位置传递，也可以按关键字传递。
  5. 默认参数可以省略，但普通参数中有默认值的参数要放在无默认值参数之后。
  6. *args 把位置参数打包成元组，**kwargs 把关键字参数打包成字典。
  7. 调用函数时，* 用于解包可迭代对象，** 用于解包字典。
  8. 未显式返回数据的函数默认返回 None。
  9. 返回多个值的本质是返回一个元组。
  10. 类型注解用于提示和静态检查，Python 默认不会在运行时强制校验。
  11. 函数内部定义的是局部变量；修改全局变量需要使用 global，但应谨慎使用。
  12. 不要直接使用列表、字典、集合作为默认参数。
